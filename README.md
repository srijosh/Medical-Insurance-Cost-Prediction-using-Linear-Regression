# Medical Insurance Cost Prediction using Linear Regression

This repository contains a project for predicting medical insurance costs using a Linear Regression model. The project employs data preprocessing techniques and trains a Linear Regression model to predict insurance charges based on various attributes of individuals.

## Introduction

Predicting medical insurance costs is a valuable task for both insurance companies and individuals. This project aims to build a machine learning model using Linear Regression to predict insurance charges based on factors such as age, BMI, number of dependents, and more. Understanding these predictions can help in planning for medical expenses.

## Dataset

The dataset used in this project is sourced from Kaggle's Medical Insurance Cost dataset. It contains information about individuals, such as age, BMI, smoking status, and more, to predict medical insurance charges. The dataset is split into training and testing sets to evaluate the model's performance.

- [Medical Insurance Cost Dataset on Kaggle](https://www.kaggle.com/datasets/mirichoi0218/insurance)

## Usage

1. Clone the repository to your local machine:

```
   git clone https://github.com/srijosh/Medical-Insurance-Cost-Prediction-using-Linear-Regression.git
```

2. Navigate to the project directory:
   cd Medical-Insurance-Cost-Prediction-using-Linear-Regression

3. Download the dataset from Kaggle and place it in the project folder

4. Open and run the Jupyter Notebook:
   jupyter notebook Medical_Insurance_Cost_Prediction.ipynb

## Model

The model used in this project is a Linear Regression model. The dataset is split into training and testing sets, and the Linear Regression model is trained to predict the insurance charges based on the features of individuals.
